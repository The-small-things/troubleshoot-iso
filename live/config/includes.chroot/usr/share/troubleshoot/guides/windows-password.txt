==========================================================================================
  RESET A FORGOTTEN WINDOWS PASSWORD with chntpw
==========================================================================================

  Only do this on a computer you own or are allowed to fix.

  This works for LOCAL Windows accounts. It does NOT work for:
    - Microsoft accounts (an email address as the login): reset those online at
      https://account.live.com/password/reset from any other device.
    - Drives encrypted with BitLocker / Device Encryption: you'll need the recovery key
      (often saved at https://account.microsoft.com/devices/recoverykey).

  1. Find the Windows partition (usually the biggest "ntfs" one):

         lsblk -f

  2. Mount it (here sdX3 – use your partition name):

         mkdir -p /mnt/windows
         mount -t ntfs3 /dev/sdX3 /mnt/windows

     "Windows is hibernated / Fast Startup" error? Start Windows once and choose
     Restart (not Shut down), or run:  ntfs-3g -o remove_hiberfile /dev/sdX3 /mnt/windows
     (this discards the hibernated session).

  3. Open the Windows account database and follow the menus:

         cd /mnt/windows/Windows/System32/config
         chntpw -i SAM

     Pick "Edit user data and passwords", choose the user, then
     "1 - Clear (blank) user password" and "2 - Unlock and enable user account".
     Quit with "q" and answer "y" to write the changes.

  4. Finish:   cd / && umount /mnt/windows
     Restart into Windows and log in with an empty password – then set a new one.

  Close this window:  exit
==========================================================================================
